## ✦ מה זה PSYSTAR

PSYSTAR אינו עוד סקוונסר. זו **פלטפורמת התקן קנונית** ממשפחת PSY, הבנויה כמערכת שכבתית שבה כל שכבה יודעת את תפקידה — ורק אותו:

- **Core** — תשתיות יסוד: תוצאות, לוגים, אירועים, שעונים.
- **Domain** — המודל המוזיקלי: תבניות, תחבורה, התקנים.
- **Protocol** — השפה המשותפת: הודעות וקידוד.
- **Engine** — התזמון: מיפוי פעימות לאירועים.
- **UI** — המסע: מצב, תצוגה, ויזואליזציה חייה.

הממשק (`web/index.html`) הוא **מסע DMT אינטראקטיבי**: קיילודוסקופ חי הנמתח עם כל טריגר, מנדלה נושמת, ארבעה ערוצי סינתזה (בס תהום, ליד קריסטל, פד ערפל, ניצוץ ישות) ורשת של 16 צעדים — הכול רץ בדפדפן, הכול מסונכרן לאותו שעון.

## ✦ עקרונות על

1. **Roast לפני ביצוע** — כל צעד נשחט קודם: למה לא, למה כן, ואיך פורצים מסגרת.
2. **הפרדה מוחלטת** — אף שכבה לא מדברת עם שכבה שלא דרך חוזה מפורש.
3. **בדיקות הן ארכיטקטורה** — לא רשת ביטחון, אלא חלק מהמערכת.
4. **אין סודות בקוד** — לא טוקנים, לא `.env`, לא שום דבר רגיש. לעולם.
5. **פרימיום או כלום** — לא בסיסי, לא מינימלי; מלא, מפורט, מקצה לקצה.

## ✦ התחלה מהירה

- `bun install` — התקנת תלויות
- `bun run dev` — הרצת המנוע
- `bun test` — כל הבדיקות
- `bun run check` — בדיקת מבנה

למסע הוויזואלי: פתחו את `web/index.html` בדפדפן, לחצו **הפעלה**, והניחו לקיילודוסקוב לנשום.

## ✦ מבנה

- `docs/` — ארכיטקטורה, roast, החלטות, בדיקות, עיצוב, מפת דרכים
- `src/` — core · domain · protocol · engine · ui
- `tests/` — unit · domain · protocol · integration
- `scripts/` — check · manifest
- `web/` — מסך ה-DMT האינטראקטיבי
- `.github/` — CI
