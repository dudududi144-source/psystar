# ✦ החלטות ✦

## D-001 · Bun ככלי ריצה
**החלטה:** Bun משמש install, run, test, build.
**סיבה:** מהירות, TypeScript-first, והתאמה לאקוסיסטם PSY.

## D-002 · הפרדת index מ-main
**החלטה:** src/index.ts מייצא API בלבד; src/main.ts מריץ.
**סיבה:** אפס side effects בזמן import — בדיקות וספריות נשארות טהורות.

## D-003 · EventBus כערוץ מרכזי
**החלטה:** כל אירוע עובר דרך EventBus מוכלל.
**סיבה:** ניתוק מלא בין scheduler, driver, ui ו-protocol.

## D-004 · ProtocolMessage כחוזה
**החלטה:** כל הודעה = type + channel + payload.
**סיבה:** שפה משותפת, ניתנת להרחבה ל-MIDI, OSC ו-WebSocket.

## D-005 · NullAudioDriver כברירת מחדל
**החלטה:** הדרייבר הראשון הוא null.
**סיבה:** לוגיקה נבדקת דטרמיניסטית, בלי תלות בחומרה.

## D-006 · Roast לפני כל צעד
**החלטה:** כל שלב מתחיל בשחיטה עצמית.
**סיבה:** חשיפת הנחות שגויות לפני שהן הופכות לחוב טכני.

## D-007 · קונסולת DMT כקובץ יחיד
**החלטה:** web/index.html עצמאי לחלוטין.
**סיבה:** נייד, ניתן לפתיחה בכל מקום, ומדגים את המערכת בלי תלות בבנייה.

## D-008 · עברית כשפת תיעוד ראשית
**החלטה:** תיעוד, הודעות וממשק בעברית.
**סיבה:** זו שפת היוצר; בהירות קודמת לאנגלית אוטומטית.
